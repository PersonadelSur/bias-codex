# The Bias Codex Artefact

Códice interactivo de los 188 sesgos cognitivos.

Idea, concepto y artefacto web por [Andrés Ahumada](https://www.linkedin.com/in/aahumadagomez/).
Sonidos FX por Oculus Sounds.
Datos y geometría derivados del Cognitive Bias Codex (John Manoogian III / Buster Benson, Wikipedia, CC BY-SA 4.0).

## Desplegar

Sitio estático: `index.html` + `audio/`. No requiere build ni configuración.

```
npx vercel --prod
```
